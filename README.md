# lampa-plugin

## Nova Skin + Lampac — персональний Premium-пілот

URL для ручного тесту:

https://hlushok.github.io/lampa-plugin/nova_skin_pr.js

Автор Nova Skin — `amikdn`. Реєстраційний автор bridge у LampaUA — `LampaUA`.

`nova_skin_pr.js` сам знаходить адресу Lampac через уже завантажений
`online.js`, тому адреса bridge не містить `lampac={localhost}` або номера групи.
Loader перевіряє наявний серверний доступ через `/lifeevents` і працює
fail-closed: лише HTTP 200 з очікуваною відповіддю дозволяє завантажити
`nova_skin_premium.js`; Viewer, анонімний користувач або мережева помилка нічого
не підвантажують. Сам Premium-build також завершується без entitlement-прапорця,
який встановлює bridge після перевірки.

Номер групи в bridge не дублюється: дозвіл повертає чинний серверний механізм
`Online.checkOnlineSearchGroup` (у поточній конфігурації Premium — група 3).

Початкові значення застосовуються лише за відсутності користувацького значення:

- фонова перевірка джерел — увімкнена;
- вигляд списку — `Плитка`.

Власний вибір користувача, зокрема `nova_skin_enabled=false`, не
перезаписується. Після входу, виходу або зміни акаунта доступ перевіряється
повторно без очищення даних Lampa; оформлення реагує на зміну доступу в поточній
сесії.

## Оформлення картки

У налаштуваннях **Nova Skin → Оформлення** доступні:

| Варіант | Вигляд |
| --- | --- |
| Рідний | Стандартна сторінка поточного онлайн-плагіна, колишнє вимкнення Nova Skin |
| Нова | Наш поточний Nova Skin; типовий вибір |
| Афіша | Широкий банер, налаштування та список серій під ним |
| Плівка | Інформація й налаштування зверху, горизонтальна стрічка кадрів унизу |
| Титри | Інформація й налаштування ліворуч, текстовий список серій праворуч |
| Титри+ | Список із кадрами та окрема права панель налаштувань |

Вибір зберігається в `nova_skin_appearance`. Без нового вибору попереднє
`nova_skin_enabled=false` означає «Рідний», а ввімкнений або новий Nova Skin —
«Нова». «Список/Плитка» налаштовує вигляд «Нова». Нові макети використовують
ті самі джерела, фільтри, прогрес і обробники перегляду; візуальним зразком
стали надані вигляди BWA.

У «Плівці» ліворуч/праворуч перемикають серії; у «Титрах» ці клавіші
перемикають колонки. У «Титрах+» праворуч відкриває налаштування,
ліворуч/«Назад» закриває панель, а вибір повертає фокус у список.

Код адаптерів і CSS зберігається в `scripts/nova-skin-appearance/`, а
`scripts/nova-skin-appearance.mjs` додає їх до Premium-build. Генератор
перевіряє наявність і унікальність використовуваних функцій upstream.

Локальний браузерний стенд `tests/nova_skin_appearance.browser.mjs` приймає
`--playwright=<index.mjs>`, `--jquery=<jquery.js>`, `--edge=<msedge.exe>`,
`--upstream=<pinned nova_skin.js>` і `--output=<каталог скриншотів>`.
Він виконує реальні рендерери й контролери на тестових даних із блокуванням
мережі. Фактичне відтворення та сумісність із фізичним ТВ перевіряються на пристрої.

## Генерація Premium

`nova_skin_premium.js` генерується з актуального upstream-файла окремим
детермінованим build-скриптом. Чисте byte-for-byte дзеркало `nova_skin.js` не
змінюється. Premium-build додає контроль доступу, керовані параметри,
виправлення вибору серії за `Lampa.Timeline.view(hash).updated`, стабільне
завантаження результатів і вибір оформлення. Відомий сторонній динамічний
додаток, який випадково замінював постери, вилучається за перевіреною сигнатурою.

Workflow `sync-nova-skin-premium.yml` щогодини фіксує immutable upstream-коміт,
перевіряє JavaScript і тести, генерує Premium-build та оновлює лише
`nova_skin_premium.js`. Якщо автор змінить патчовані ділянки, build зупиниться
замість публікації неперевіреного файла.

Майбутнє штатне підключення в `LampaWeb.customPlugins`:

```json
{
  "url": "https://hlushok.github.io/lampa-plugin/nova_skin_pr.js",
  "status": 1,
  "name": "Nova Skin Premium",
  "author": "LampaUA"
}
```

На етапі пілота цей запис у `init.conf` не додається: посилання встановлюється
вручну лише на тестовому пристрої.
